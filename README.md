# 在身边（ZaiShenBian）— 异地子女养老协同平台 MVP

> 你不在身边的日子，让爱替你在。

按《在身边-产品需求文档PRD V1.0》实现的 **可运行 MVP**：零依赖 Node.js 服务端 + SQLite + Web 三端（子女端 / 老人端 / 服务商端）。

## 快速开始

```bash
node -v                # 需要 Node >= 22.5（内置 node:sqlite）
npm run seed           # 生成演示数据（李家：2子女+2老人+1陪诊师）
npm start              # http://localhost:8081
npm test               # 70 项全流程 API 测试
```

## 技术说明

- `server/index.js` HTTP + 路由（原生 http，无任何 npm 依赖）
- `server/db.js` SQLite 表结构与工具（node:sqlite，WAL）
- `server/alerts.js` 预警引擎（阈值 + 15s 定时扫描）
- `server/emergency.js` 应急分级状态机（`SOS_TIME_SCALE` 可缩放，测试用）
- `server/dispatch.js` 派单引擎
- `web/` 三端合一 SPA（子女端 5 Tab + 老人端大字模式 + 服务商工作台）
- `tests/api-test.js` 70 项端到端断言（含权限边界）

数据文件在 `data/zaishenbian.db`（gitignore）。健康数据仅存本机，符合 PRD 隐私最小采集原则；分享卡片自动脱敏。

## 与 PRD 完整版的差距（MVP 边界）

- 推送为轮询通知（8s）+ 页面弹层，未接 APNs/FCM/SMS/电话外呼
- AI 解读为规则模板，未接大模型；语音交互/方言 ASR 未实现
- 设备数据为模拟上报接口，未接真实 MQTT/BLE 硬件
- 支付为演示直通，未接微信/支付宝/长护险
- 体检报告 OCR 未实现（文字归档代替）
